# 測定せよ
サイトを改善するにはまずは測定をしよう
Googleが提供している無料のツールで測定可能です

# フィールドで計測する
## RUMデータを使え
RUMデータはリアルタイムユーザーモニタリングデータで、その名の通りサイトの実際のユーザーが体験したパフォーマンスのデータのこと
フィールドデータとも呼んでる

RUMデータの主な使い道はGoogleがそのサイトのWeb Vitalsの指標を満たしているかで使う
明言していないが、SEOの判定に使ってるのかもしれない
Googleが溜め込んだデータを開発者にも公開している仕組みがRUMデータというわけだ

## RUMデータを計測するツール
### Chrome DevTools
パフォーマンスタブでラボデータとフィールドデータを確認することができる
![[dev-tools-field.png]]
### PageSpeed Insights
PageSpeed Insightsは過去28日間のページレベルとオリジン（サイト）レベルのパフォーマンスレポートを作成してくれる
スコアの低い指標については改善のヒントもくれる
![[page-speed-insight.png]]
### Search Console
ページ単位のパフォーマンスレポートを作成できる
PSIがどのサイトでも利用できるのに対して、Search Consoleは自分が所有者のページしか計測できない
過去のパフォーマンスデータも確認することができる
### CrUx Vis
CrUX History APIをベースに構築されているWebツールでWeb Vitalsの指標すべての過去から現在に至るまでの推移を見ることが可能

## RUMデータを使えないケース
RUMデータはすべてのサイトに存在するわけではない
当然だが、アクセスが少ないサイトはそれだけデータが集まりにくいのでRUMデータに頼った計測は不可能
その場合は後述のラボデータを利用してパフォーマンスを計測しよう

## 頑張ってRUMデータを使う方法
とはいえベストは実際のユーザーが体験したパフォーマンスデータで測定した方がいいに決まってる 開発と本番ではデバイスが違うし、デバイスが違えば性能違う、ネットワークの速さもまちまちだし、何よりデータ量も一般的に本番の方が膨大だ

## 自分で収集する
ここで朗報、なんと自分でもRUMデータを収集できるらしい 2つの方法で収集できる
- 専用のRUMプロバイダを利用する
- 独自のツールを設定する
2つともなんじゃそりゃって感じ 1つずつ見ていこう

### 専門のRUMプロバイダ
まずは専門のRUMプロバイダ
これは要はサードパーティサービスでタグを埋め込むだけで計測しますよってやつ
本番環境でCWV系のAPIを叩いてデータ収集する（CWVの値はGoogleが公開しているライブラリweb-vitalsで簡単に計測できる）
あとは、サービスによってダッシュボード作ったり、改善提案したりそこはまちまちだろう

### 独自のツールを設定する
これもやってることは専門のRUMプロバイダを設定するのと同じ、独自で実装するかSaaSのサービスを利用するかの違い
SaaSでできるだから自分でやれないことはないだろうということ
Googleはweb-vitalsという名前のJavaScriptライブラリを提供している
これを使えばウェブバイタルを計測するためのAPIが利用できるようになり、RUMデータの収集とレポートが可能となる
たとえば、CLSならばLayout Instability APIで収集できる
独自のツールを実装する方法は別の機会に語ることにする

## データの扱い
当然だが`web-vitals`で収集したデータはどこかに溜め込んで見れる状態にしよう
独自のDBでダッシュボードのような監視システムを作ってもいいし
無料で使えるGoogle Analyticsに送ってもいい

Googleはデータを解釈するときには平均値や中央値を見るのではなく75パーセンタイルの値でGOODの指標になっているかどうかで判断する
フィールドデータはさまざまなユーザーがいるため

# ラボで計測する
実際のパフォーマンスはフィールドで計測するに越したことはないが、まだ未公開のサイトや極端にトラフィックの少ないページは現実的じゃない
そんな時はラボツールで計測しろ

実際のユーザー、実際のデータではない管理された環境で計測されるので合成データとも呼ばれる
ラボデータの強みは本番環境前から計測できるので、開発のワークフローに組み込んだり、CIに組み込んだりできること
常にラボデータの計測を回して少なくともラボデータで悪化していないことを確認しながらリリースフローを回すことができる

## ラボデータを計測できるツール
ウェブバイタルのラボデータを計測するのは次のツールを使え
### Chrome DevTools
パフォーマンスパネルでLCP・CLS・INPを勝手に計測してる
もし、CrUXにデータがあればそれも勝手に表示してくれる
優れもの
![[dev-tools-cwv.png|400]]
### Lighthouse
灯台というツールでも計測できる
これはいろんな場所から計測できる
Chrome DevToolsの中にもあるし
![[01_study/blog/blog/260801_measure_web_vitals/img/light-house.png|408]]
Chromeの拡張としても存在する
![[chrome-add-on.png|456]]
特徴的なのがLighthouse CIというnpmパッケージも公開されているのでCIを組めばPRごとにLighthouseを回すなんてことも可能
ただしLighthouse CIは時間がかかることがあるので実行時間制限がある環境では注意しなければならない
